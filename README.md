# 🔐 Cryptography & Encryption Projects

Welcome to my cryptography repository! This space is dedicated to various projects, algorithm implementations, and hands-on cryptographic tools built from scratch.

This repository contains source code, scripts, and algorithms exploring classic and modern cryptography concepts. The primary focus is understanding encryption mechanisms, key schedules, bitwise operations, and foundational cryptographic algorithms.
